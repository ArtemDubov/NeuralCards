Дополнительные модули:
1.	Система кастомизации интерфейса, предоставляющая пользователю на выбор 18 визуальных тем (9 цветов × 2 режима) с возможностью создания пользовательских пресетов, настройки плотности интерфейса и выбора типа аватара (буква, эмодзи или изображение).
2.	Система социального взаимодействия: полноценный чат в реальном времени через WebSocket, система друзей с заявками и блокировкой, поиск пользователей, публичные наборы карточек с возможностью копирования.
3.	AI-сервисы: распознавание речи (STT) через faster-whisper, синтез речи (TTS) через gTTS с поддержкой 30+ языков, перевод текста через deep-translator с автоопределением языка.
4.	Импорт/экспорт данных: поддержка форматов CSV и JSON для переноса наборов карточек между аккаунтами и резервного копирования.
5.	Аналитика прогресса: статистика тренировок (общее количество карточек, время обучения, серии дней), графики активности по дням, детальная аналитика публичных профилей с тепловой картой активности, распределением по режимам и любимыми наборами.
