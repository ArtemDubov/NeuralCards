## РАЗДЕЛ 2. ПРОЕКТИРОВАНИЕ

### Требования к разработке

**Функциональные и технические требования к готовому продукту:**

**Функциональные требования:**

1. **Аутентификация и управление профилем:**
   - Регистрация с валидацией email и пароля
   - Вход с генерацией JWT access/refresh токенов
   - Получение и обновление профиля (имя, биография, язык, аватар)
   - Загрузка и удаление аватара (letter/emoji/url)
   - Удаление аккаунта с подтверждением пароля

2. **Управление наборами карточек:**
   - Создание наборов с названием, описанием, тегами, публичностью
   - Редактирование и удаление наборов
   - Добавление карточек с текстом, изображениями, аудио, видео на обеих сторонах
   - Drag & Drop сортировка карточек
   - Пагинация при просмотре больших наборов (>100 карточек)

3. **Режимы тренировок (5 режимов):**
   - **Practice:** классический переворот карточек с оценкой сложности
   - **Quiz:** викторина с выбором правильного ответа из 4 вариантов
   - **Marathon:** прохождение всего набора подряд без остановок
   - **Dictation:** диктант с вводом текста и проверкой через распознавание речи
   - **Matching:** сопоставление пар на скорость

4. **Социальные функции:**
   - Поиск пользователей по имени/email
   - Отправка запросов в друзья
   - Принятие/отклонение запросов
   - Список друзей с возможностью удаления
   - Чат в реальном времени через WebSocket (сообщения, реакции, закрепление, ответы)
   - История сообщений с пагинацией
   - Совместный доступ к наборам с ролями (editor/viewer)
   - Глобальный лидерборд с фильтрацией по периодам

5. **Аналитика и статистика:**
   - Dashboard с общей статистикой (карточки, время, серии)
   - График прогресса по дням
   - Распределение активности по дням недели
   - Распределение по режимам тренировок
   - Тепловая карта активности (GitHub-style calendar)
   - Прогноз обучения
   - Еженедельные отчёты
   - Статистика по наборам

6. **Кастомизация интерфейса:**
   - 30+ тем оформления (minimalism, game, cyberpunk и др.)
   - Ручная настройка цветов (primary, secondary, accent, background, text)
   - Выбор шрифтов из списка или загрузка через Google Fonts
   - Настройка плотности интерфейса (compact/normal/spacious)
   - Тёмный режим с инверсией схемы
   - Синхронизация настроек между localStorage и сервером

7. **Избранное:**
   - Добавление в избранное наборов, карточек, друзей, режимов
   - Просмотр списка избранных элементов
   - Удаление из избранного

8. **Импорт/Экспорт:**
   - Экспорт наборов в CSV, JSON, TXT
   - Импорт из файлов с автоопределением языков
   - Валидация формата при импорте

9. **AI-сервисы:**
   - Распознавание речи (STT) через Faster-Whisper
   - Синтез речи (TTS) через gTTS с поддержкой 50+ языков
   - Перевод текста через deep-translator

10. **Гостевой режим:**
    - Практика без регистрации на публичных наборах
    - Временные сессии с ограниченным функционалом

**Технические требования:**

**Архитектурные:**
- Клиент-серверная архитектура (SPA + REST API + WebSocket)
- Stateless-аутентификация через JWT в localStorage
- Слоистая архитектура бэкенда: routes → services → models
- Модульность фронтенда: features/, pages/, components/
- Защита маршрутов через AuthGuard

**Производительность:**
- Время загрузки главной страницы: < 2 секунд
- Время ответа API: < 500 мс (95-й перцентиль)
- Поддержка наборов до 1000 карточек без деградации
- WebSocket соединение с автоматическим переподключением (exponential backoff)

**Безопасность:**
- Хэширование паролей через bcrypt
- JWT access token: 30 минут, refresh token: 7 дней
- Валидация всех входных данных
- CORS policy с whitelist доменов
- Rate limiting на критичных endpoints

**Масштабируемость:**
- Возможность миграции с SQLite на PostgreSQL
- Поддержка горизонтального масштабирования бэкенда
- Кэширование часто запрашиваемых данных

**Комментарии к архитектуре:**

**Ключевые архитектурные решения:**

1. **Stateless-аутентификация через JWT:** Access token (30 минут) и refresh token (7 дней) в localStorage, не требуется сессия на сервере — упрощает масштабирование.

2. **Модульность тренировок:** Каждый режим — отдельный компонент React, общий сервис на бэкенде для обработки ответов — легко добавлять новые режимы.

3. **Real-time чат через WebSocket:** Без polling, мгновенная доставка сообщений, WebSocket Manager управляет подключениями, автоматическое переподключение при разрыве связи.

4. **Синхронизация настроек темы:** При загрузке: localStorage (мгновенно) → сервер (синхронизация). При изменении: сервер → localStorage (сохранение). Реактивное обновление через Context API.

5. **Слоистая архитектура бэкенда:** Routes (валидация, HTTP responses) → Services (бизнес-логика) → Models (работа с БД через ORM). Четкое разделение ответственности.

6. **Поддержка мультимедиа:** Файлы сохраняются в media/ с UUID-именами, в БД хранятся только пути — легкая миграция на облачное хранилище (S3) в будущем.

**Преимущества архитектуры:** Масштабируемость (stateless backend, модульный frontend), поддерживаемость (четкое разделение слоев), производительность (кэширование TanStack Query, WebSocket), безопасность (JWT, bcrypt, валидация), гибкость (легко добавлять функции).
