## РАЗДЕЛ 2. ПРОЕКТИРОВАНИЕ

### Требования к разработке

**Функциональные:**
- Аутентификация (JWT), CRUD наборов/карточек с мультимедиа
- 5 режимов: Practice, Quiz, Marathon, Dictation, Matching
- Друзья, чат WebSocket, лидерборд
- 30+ тем, импорт/экспорт, STT/TTS/перевод

**Технические:**
- Frontend: React 19, Zustand, TanStack Query, Tailwind CSS
- Backend: FastAPI, SQLAlchemy, WebSocket
- База данных: SQLite (dev) → PostgreSQL (prod)
- AI: Faster-Whisper, gTTS, deep-translator

**Инструменты:** Vite, Postman, Mermaid, Git

### Архитектура продукта

**Frontend (React SPA):**
- Модули: auth, cardSets, training (5 режимов), chat, profile, friends, stats
- Хранилища: Zustand (глобальное состояние), TanStack Query (кэш), LocalStorage
- Routes: 20+ защищённых маршрутов с AuthGuard

**Backend (FastAPI):**
- Слои: routes → services → models
- 50+ REST API endpoints + WebSocket endpoint
- Middleware: CORS, JWT auth, error handling

**База данных:**
- 14 таблиц с каскадными удалениями
- Составные уникальные индексы

**Взаимодействие:**
- Пользователь ↔ React ↔ REST API ↔ FastAPI ↔ SQLite
- Real-time чат: WebSocket (без polling)

## РАЗДЕЛ 4. ОБЕСПЕЧЕНИЕ КАЧЕСТВА

### Результаты тестирования

**Альфа-тестирование (внутреннее):**
- 21 сценарий → 100% успешно
- 0 критических багов, 5 minor (исправлены)

**Бета-тестирование (8 пользователей, 2 недели):**
- Среднее время сессии: 18 минут
- Retention rate: 75% (следующий день), 62% (неделя)
- **Отзывы:** "Matching затягивает!", "Темы потрясающие", "Чат как в Telegram"

**Проблемы и решения:**
1. Потеря состояния сессии → Zustand persist middleware
2. Медленная загрузка >100 карточек → пагинация + виртуализация
3. Рассинхронизация тем → правильный порядок инициализации

### SWOT-анализ

**Strengths:** 5 режимов, 30+ тем, социальные функции, AI-сервисы, современный стек  
**Weaknesses:** единый разработчик, SQLite вместо PostgreSQL, нет мобильного приложения  
**Opportunities:** миграция на PostgreSQL, React Native, премиум-подписка, B2B продажи  
**Threats:** конкуренция (Quizlet, Duolingo), зависимость от внешних API

### Риски и смягчение

**Ключевые риски:**
1. Единый разработчик → open source, документация, поиск контрибьюторов
2. Производительность → план миграции на PostgreSQL, Redis кэширование
3. Безопасность → JWT, bcrypt, валидация, rate limiting
4. Монетизация → премиум-план ($4.99/мес), B2B лицензии ($199/год)

### Перспективы развития

**Технологические:** PostgreSQL, облачный хостинг, CI/CD, GPU для Whisper, PWA  
**Новые функции:** Sprint режим, Audio Quiz, достижения, групповые чаты, ML-рекомендации  
**Практическое внедрение:** пилот в языковых школах, интеграция с Moodle, marketplace наборов  
**Коммерческая модель:** Freemium → Premium $4.99/мес → Enterprise $199/год

### Бизнес-модель

**Customer Segments:** студенты/школьники (B2C), преподаватели/школы (B2B), корпоративные клиенты  
**Value Proposition:** персонализация, 5 режимов, социальные функции, бесплатная базовая версия  
**Revenue Streams:** Premium подписка ($4.99/мес), B2B лицензии ($199/год), marketplace (10% комиссия)  
**Cost Structure:** хостинг $20-50/мес, домен $15/год, AI-сервисы $10-30/мес  
**Break-even:** ~200 premium подписчиков, ROI через 6-8 месяцев
